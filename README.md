# S3GBR
# Repository of the project of the S3GBR group of EPITA students.
# To use the program  :
# First put you input images in the folder data/input/ 
# Compile the pretreatment program with the command 'make pretreatment' at the root
# Execute the compiled program with './pretreatment data/input/input_image.png'
#                    with input_image.png the name of you image
#
# Then compile the solving with 'make solving' at the root
# Execute the compiled program with './solving data/images/treated_image.png'
#                    with treated_image.png the name of you image
#
# You can delete the executable and all the ouput files with 'make clean'
